IFCT PUBLIC INFORMATION PORTAL — V1

Open index.html in a modern browser.
For best results, use a local development server (for example VS Code Live Server) although the site does not require a backend.

Audio:
- Procedurally generated in-browser with Web Audio API.
- No external music files, CDN calls, analytics, or third-party resources.
- Browser autoplay restrictions are used intentionally as part of the ENTER threshold.

Responsive:
- Desktop-first cinematic layout.
- Dedicated tablet and narrow/mobile compositions.
- No critical interaction depends on hover.
- Reduced-motion is respected.
